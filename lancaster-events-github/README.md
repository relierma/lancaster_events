# Lancaster, CA Events — March 29 – April 12, 2026

A curated guide to 40+ events in the Lancaster/Antelope Valley area.

## Local Development

```bash
npm install
npm run dev
```

## Deploy to GitHub Pages

This project is pre-configured for GitHub Pages with a GitHub Actions workflow included.

1. Push this repo to GitHub
2. Go to **Settings → Pages → Source → GitHub Actions**
3. Every push to `main` will auto-build and deploy
